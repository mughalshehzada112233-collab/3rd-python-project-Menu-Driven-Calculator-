# 3rd-python-project-Menu-Driven-Calculator-
Create a simple menu-driven calculator. The user will select an arithmetic operation from a menu, enter two
numbers, and see the answer.
• Show a menu for addition, subtraction, multiplication, division, and exit.
• Ask the user to choose an operation.
• Take two numbers from the user after a valid operation is selected.
• Use if, elif, and else to perform the selected calculation.
• Use continue for an invalid menu choice.
• Use break when the user chooses Exit.
• Keep the program running with a while loop.
